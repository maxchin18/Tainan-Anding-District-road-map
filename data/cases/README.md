# 施工／維修案件資料格式

「施工」分頁會讀取 `index.json`，依年度列出各案件檔（GeoJSON 點位）。

## 最簡單的方式：Excel → CSV → 轉檔

1. 用 Excel 整理案件，欄位如下（第一列為標題）：

   | 標題 | 類別 | 里別 | 派工日期 | 完工日期 | 廠商 | 金額 | X | Y | 備註 |
   |---|---|---|---|---|---|---|---|---|---|
   | 港尾里農路坑洞修補 | 搶險搶修 | 港尾里 | 115/03/01 | 115/03/10 | ○○營造 | 12000 | 171183 | 2556083 | |

   - X、Y 可填 **TWD97**（如 171183, 2556083）或 **WGS84 經緯度**（如 120.2306, 23.1047）
   - 日期可用民國（115/03/01）或西元（2026-03-01）

2. 另存為 CSV，執行：

   ```bash
   python scripts/cases_csv_to_geojson.py 115養護.csv --year 115 --label "115年道路及公共設施養護維修"
   ```

3. 產生 `data/cases/115養護.geojson` 並自動登錄到 `index.json`，推上 GitHub 後即顯示。

## index.json 結構

```json
{
  "groups": [
    { "year": "115", "items": [ { "label": "115年一般工程", "file": "115else.geojson" } ] }
  ]
}
```

## 案件 GeoJSON 屬性

| 屬性 | 說明 |
|---|---|
| title | 案件名稱 |
| type | 類別（搶險搶修／一般工程／養護維修…） |
| village | 里別 |
| dispatchDate / finishDate | 派工／完工日期（YYYY-MM-DD），地圖依完工日期由近（藍）到遠（紅）著色 |
| vendor | 廠商 |
| amount | 金額（元） |
| note | 備註 |

> 請勿放入個資（通報人姓名、電話）；本資料夾內容會公開於網站。
