# 通報後端與管理後台部署（Google Apps Script）

網站本身是純靜態（GitHub Pages），民眾通報與管理後台需要一個後端。用公所的 Google 帳號即可免費架設，**資料只存在公所自己的試算表與雲端硬碟**。

## 一、部署後端

1. 建立一份 Google 試算表，命名如「安定區道路通報」。
2. 試算表選單 **擴充功能 → Apps Script**，把 `Code.gs` 內容整份貼上、儲存。
3. 右上 **部署 → 新增部署作業**，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 授權後複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
5. 打開 `js/config.js`，填入 `reportEndpoint: '剛剛的網址'`，推上 GitHub。

> 之後修改 `Code.gs` 需「部署 → 管理部署作業 → 編輯 → 版本選『新版本』」，網址不變。

## 二、建立後台帳號

帳號只能在 Apps Script 編輯器裡建立，網站上沒有註冊功能。

1. 在 `Code.gs` 找到 `addAccount()`，改成要建立的帳號：
   ```js
   function addAccount() {
     setupAccount_('chen', '至少10碼的密碼', 'handler');
   }
   ```
2. 上方函式選單選 `addAccount` → **執行**。
3. **執行完立刻把密碼改回空白再儲存**（避免密碼留在程式碼裡）。

| 角色 | 代碼 | 可以做的事 |
|---|---|---|
| 檢視者 | `viewer` | 看案件列表、地圖、說明、照片；聯絡方式**遮罩** |
| 承辦人 | `handler` | 檢視者全部 ＋ 看完整聯絡方式、更新處理狀態與回覆 |
| 管理者 | `admin` | 承辦人全部 ＋ 匯出 CSV、看操作紀錄 |

- 重設密碼：同一帳號再執行一次 `setupAccount_`，舊的登入會全部失效。
- 刪除帳號：在 `removeAccount()` 填入帳號後執行。
- 列出帳號：執行 `listAccounts()`，到「執行記錄」查看。
- 懷疑外洩：執行 `revokeAllSessions()`，所有人立即登出。

後台網址：`https://<網站>/admin.html`（首頁頁尾與「工具」分頁底部有連結）。

## 三、日常作業

- 新通報出現在試算表「通報」工作表，照片存在雲端硬碟「安定區道路通報照片」資料夾。
- 承辦人可在後台改狀態（待處理／處理中／已完成／不受理）並填寫處理說明；也可以直接改試算表。
- 「操作紀錄」工作表記錄每次登入、登入失敗與狀態變更。

## 四、安全設計

| 項目 | 做法 |
|---|---|
| 密碼 | 加鹽、雜湊 2000 次後存在「指令碼屬性」，試算表與程式碼中都沒有明文 |
| 登入權杖 | HMAC-SHA256 簽章，8 小時到期；存在瀏覽器 sessionStorage，關閉分頁即登出 |
| 暴力破解 | 同一帳號連錯 5 次鎖 15 分鐘；全站 15 分鐘內錯 50 次暫停所有登入 |
| 權限 | 每個請求都在後端重新驗證角色，前端隱藏按鈕只是介面，繞過也無法操作 |
| 個資 | 公開看板只輸出類別／位置／狀態／回覆；說明、聯絡方式、照片只有登入者可見 |
| 照片 | 只能讀取該案件本身的照片檔，無法藉此讀取雲端硬碟其他檔案 |
| 注入 | 寫入試算表前，以 `= + - @` 開頭的內容加上單引號，避免公式注入；匯出 CSV 同樣處理 |
| 濫用 | 通報限安定區附近座標與既定類別，並有每 10 分鐘 60 筆的上限 |
| 前端 | 不放任何金鑰或密碼；後台頁面設定 `noindex` 不被搜尋引擎收錄 |

## 五、本機測試

不用部署也能測試整個流程（模擬後端，資料在記憶體）：

```bash
python scripts/dev_server.py
```

開 http://localhost:8766/admin.html ，測試帳號 `demo-admin`／`demo-handler`／`demo-viewer`，密碼 `local-test-only`（僅本機模擬伺服器有效，與正式後端無關）。
