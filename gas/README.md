# 通報後端部署（Google Apps Script）

網站本身是純靜態（GitHub Pages），民眾通報需要一個後端接收。以下用公所的 Google 帳號即可免費架設：

1. 建立一份 Google 試算表，命名如「安定區道路通報」。
2. 試算表選單 **擴充功能 → Apps Script**，把 `Code.gs` 內容整份貼上、儲存。
3. 右上 **部署 → 新增部署作業**，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 授權後複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
5. 打開 `js/config.js`，填入 `reportEndpoint: '剛剛的網址'`，推上 GitHub。

## 日常作業

- 新通報會出現在試算表「通報」工作表，照片存在雲端硬碟「安定區道路通報照片」資料夾。
- 承辦人把 **狀態** 欄改成「處理中」「已完成」，並可在 **處理說明** 欄回覆；網站「施工 → 民眾通報看板」會同步顯示顏色。
- **聯絡方式與照片不會對外公開**（`doGet` 不輸出這兩欄）。

## 安全說明

- 不在前端放任何密鑰：前端放金鑰等於公開，無保護效果。
- 後端以座標範圍、類別白名單、字數上限與照片大小限制過濾不當資料；表單另有機器人陷阱欄位。
- 若遭濫用，可在 Apps Script「部署管理」中停用該版本，網站會自動退回「本機暫存＋列印通報單」模式。
